\# MiniKart - Full Stack E-commerce Application



MiniKart is a beginner-friendly full-stack e-commerce application built using Java, Spring Boot, React, and MySQL.



The application allows users to view products and add new products through a web interface.



\## Features



\- View all products

\- Add new products

\- REST APIs using Spring Boot

\- React-based frontend

\- MySQL database integration

\- Product data stored permanently in the database

\- React frontend connected with Spring Boot backend

\- CORS configuration for frontend-backend communication
